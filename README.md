# Adelkis Studio · versiones

Instaladores de Adelkis Studio para Windows y el `latest.json` que consulta la app para actualizarse
sola. El código está en un repositorio privado.

- **Instalar por primera vez:** descargá `Adelkis.Studio_<versión>_x64-setup.exe` de la última
  [versión publicada](../../releases/latest) y ejecutalo.
- **Actualizar:** la app avisa cuando hay una versión nueva y se instala con un clic. Las novedades
  de cada versión aparecen al abrirla y en Ayuda → Novedades.

Cada instalador está firmado: la app verifica la firma antes de instalar una actualización.
